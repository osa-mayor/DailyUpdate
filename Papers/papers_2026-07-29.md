## 4. [Rethinking Classifier-Free Guidance in On-Policy Diffusion Distillation](https://huggingface.co/papers/2607.24731)
**Upvotes**: 61 | **도입 난이도**: 중 | **신뢰도**: 상
**arXiv**: https://arxiv.org/abs/2607.24731

**태그**: Diffusion, Distillation, Generative Models, Video Generation, Vision, Video, Inference

![Thumbnail](images/Rethinking_Classifier-Free_Guidance_in_On-Policy_Diffusion_Distillation_img.jpg)

### 📌 한 줄 요약
CFG를 사용하는 온폴리시 증류(OPD) 시 발생하는 부정적 브랜치 비대칭(NBA) 문제를 해결하여 비디오 생성 모델의 지식 전이 효율을 높인 연구입니다.

### 🔑 핵심 포인트
- CFG 환경에서 기존 OPD 방식이 겪는 '부정적 브랜치 비대칭(NBA)' 현상 규명
- 양성 예측과 CFG 방향을 분리하여 학습하는 PDM(Positive-Direction Matching) 제안
- 가이드 스케일 변화에 강건한 비디오 생성/제어 성능 확보

### 🧑‍💻 개발자 관점
모델 증류(Distillation) 시 CFG 스케일을 높여도 성능이 무너지지 않는 견고한 생성 모델을 구축하는 데 중요한 가이드를 제공합니다.

### 🚀 실무 적용 아이디어
- 기존 CFG 기반 증류 루틴에 PDM 목적 함수를 적용하여 성능 변화 비교
- 가이드 스케일(Guidance Scale) 변화에 따른 생성 품질의 안정성 테스트
- 비디오 생성 모델의 텍스트-이미지 정렬(Alignment) 성능 측정

### ⚠️ 리스크/한계
- 제안된 PDM 방식이 모든 유형의 CFG 스키마에서 범용적으로 작동하는지에 대한 추가 검증 필요
- 분리된 브랜치 학습 시 계산 복잡도 증가 가능성

### 📝 초록 기반 상세 설명
최근 확산 모델의 온폴리시 증류(OPD) 방식은 CFG(Classifier-Free Guidance) 환경에서의 동작 원리가 명확히 밝혀지지 않았습니다. 기존 방식은 CFG가 적용된 최종 결과물만을 매칭하려 하여, 양(+)과 음(-)의 브랜치 오차가 서로 상쇄되는 식별 불가능성 문제를 야기합니다. 특히 교사 모델의 음성 브랜치에 학생 모델이 알 수 없는 정보가 포함될 경우, 오차가 한쪽은 줄고 다른 쪽은 늘어나는 '부정적 브랜치 비대칭(NBA)' 현상이 발생합니다. 이를 해결하기 위해 양성 예측과 CFG 조건 방향을 분리하여 제약하는 Positive-Direction Matching(PDM) 목적 함수를 제안합니다. 실험 결과, PDM은 가이드 스케일에 민감한 비디오 제어 작업에서 더 견고하고 효과적인 지식 전이 성능을 보여주었습니다.

모델을 재학습시키지 않고도 추론 단계(Inference-time)의 최적화만으로 생성 결과의 정밀도를 높일 수 있는 실용적인 방법론입니다.

### 🚀 실무 적용 아이디어
- T2ICompBench 데이터셋을 활용한 기존 모델과의 성능 비교 실험
- 제안된 하이브리드 가이던스 전략의 파라미터 변화에 따른 품질 변화 관찰
- 특정 도메인(예: 복잡한 사물 배치)에서의 가이던스 스텝 효율성 테스트

### ⚠️ 리스크/한계
- 모델 내부 보상에 의존하므로 베이스 모델의 성능 범위 내로 결과가 제한될 수 있음
- 샘플링 단계에서의 추가 연산 비용 발생 가능성

### 📝 초록 기반 상세 설명
최근 텍el-to-image 모델은 강력해졌으나, 복잡한 구성적 프롬프트에 대해 정확한 이미지를 생성하는 데 어려움을 겪고 있습니다. 기존 방식은 복잡한 개념들이 겹치거나 누락되는 문제가 발생합니다. 본 논문은 TILT라는 학습이 필요 없는 테스트 타임(test-time) 프레임워크를 제안합니다. 이는 모델 내부의 분포를 활용하여 모든 개념이 공존하는 샘플을 favoring하는 보상 함수를 정의합니다. 이 보상은 외부 모델 없이 폐쇄형(closed-form)으로 계산되어 효율적인 가이던스를 제공합니다. 실험 결과, 이미지 품질을 유지하면서도 복잡한 프롬프트에 대한 정렬 성능을 크게 향상시켰습니다.
