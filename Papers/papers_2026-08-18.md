## 2. [Self-Supervised Visual On-Policy Distillation](https://huggingface.co/papers/2608.14144)
**Upvotes**: 143 | **도입 난이도**: 하 | **신뢰도**: 상
**arXiv**: https://arxiv.org/abs/2608.14144

**태그**: Self-Supervised, Knowledge Distillation, Data Augmentation, Vision-Language, Vision, Benchmark, Distillation

![Thumbnail](images/Self-Supervised_Visual_On-Policy_Distillation_img.jpg)

### 📌 한 줄 요약
정답 데이터 없이도 데이터 증강(Augmentation)의 비대칭성을 이용해 강력한 교사 모델 효과를 내는 자기주도 학습법

### 🔑 핵심 포인트
- 특권 정보(정답, 강력한 교사) 없이 데이터 증강의 비대칭성만으로 학습 신호 생성
- S^2VOPD: 원본 이미지(Teacher)와 강한 증강 이미지(Student) 간의 분포 차이를 이용한 자기주도 학습
- 증강의 강도와 태스크 일관성(Task-consistency)이 성능의 핵심 요소임을 규명

### 🧑‍💻 개발자 관점
라벨링된 정답 데이터가 부족한 상황에서, 기존 모델의 성능을 데이터 추가 없이 증강 기법만으로 끌어올릴 수 있는 효율적인 방법론을 제시합니다.

### 🚀 실무 적용 아이디어
- 현재 사용 중인 Vision 모델에 다양한 강도의 Augmentation을 적용하여 성능 변화 관찰
- Task-relevant한 정보가 유지되는 범위 내에서 증강 강도 최적화 실험
- Symmetric(대칭적) 증강이 아닌 Asymmetric(비대칭적) 증강 구조로 파이프라인 설계

### ⚠️ 리스크/한계
- 증강이 너무 강해 태스크에 필요한 핵심 정보까지 사라질 경우 성능 저하 위험
- 특정 도메인이나 태스크에 따라 최적의 증강 조합이 달라질 수 있음

### 📝 초록 기반 상세 설명
기존의 시각적 온폴리시 증류(On-policy distillation)는 정답이나 강력한 교사 모델 같은 특권 정보(Privileged information)에 의존해 성능을 높였습니다. 하지만 정답 데이터가 없는 상황에서 어떻게 정보의 비대칭성을 확보할 것인가라는 근본적인 문제가 존재합니다. 본 논문은 교사에게 정보를 더하는 대신 학생으로부터 정보를 빼는 역발상적 접근법을 제안합니다. 이를 통해 제안된 S^2VODP는 원본 이미지 기반의 교사 분포를 강한 증강이 적용된 학생 분포로 증류하는 방식입니다. 실험 결과, 별도의 정답 없이도 기존의 특권 정보 기반 방식의 96% 성능을 회복하며 최첨단 모델들을 상회하는 성능을 보였습니다.

### 📌 한 줄 요약
온폴리(On-policy) RL에서 특정 보상에 최적화할 때 발생하는 '지원 범위 재편(Support Reshaping)' 현상과 그로 인한 성능 불균형 문제를 규명함

### 🔑 핵심 포인트
- RLVR 과정에서 특정 보상에 최적화될 때 다른 목표를 위한 행동 공간(Support)이 축소되는 현상 발견
- 성능 향상이 주로 응답 초기 토큰의 재배열(Reranking)을 통해 발생하며, 이것이 이후 태스크의 탐색 가능성에 영향을 미침
- 한 쪽 태스크의 최적화가 다른 태스크의 성공 확률(best@k)을 낮추는 상충 관계(Trade-off) 존재

### 🧑‍💻 개발자 관점
특정 태스크(예: 수학) 성능을 높이는 RL이 모델의 범용성이나 다른 태스크(예: 지시 이행)의 잠재력을 파괴할 수 있음을 인지해야 합니다.

### 🚀 실무 적용 아이디어
- 단일 목적 RL 학습 시, 학습 데이터/보상 설계가 다른 태스크의 분포를 어떻게 변화시키는지 모니터링
- 학습 과정에서 pass@1과 best@k 지표를 동시에 관찰하여 탐색 범위 축소 여부 확인
- 멀티태스크 학습 시, 태스크 간 보상 충돌을 방지하기 위한 정규화 기법 적용

### ⚠️ 리스크/한계
- 특정 보상에 과적합될 경우 모델의 행동 범위가 좁아져 향후 학습이 불가능해질 위험이 있음
- 엔드포인트 지표(pass@1) 개선이 반드시 모델의 전체적인 능력 향상을 의미하지 않음

### 📝 초록 기반 상세 설명
검증 가능한 보상을 사용하는 온폴리 강화학습(RLVR)은 현재 목표 성능을 높일 수 있지만, 미래의 다른 목표를 달성할 수 있는 행동 양식을 희귀하게 만드는 문제를 야기합니다. 연구진은 이를 'verifier-induced support reshaping'이라 정의하고, 고정된 샘플링 예산 내에서 도달 가능한 성공 궤적의 범위를 분석했습니다. 수학적 추론과 지시 이행(IFEval) 태스크를 대상으로 반복적인 검증 기반 샘집과 양방향 학습을 수행했습니다. 실험 결과, 특정 태스크의 성능 향상이 다른 태스크의 성공 가능성을 낮추는 상충 관계가 확인되었으며, 이러한 변화는 주로 응답 초기 토큰 분포에 집중되었습니다. 결론적으로 엔드포인트 성능 향상이 미래의 학습 가능성이나 다중 작업 능력을 보장하지 않음을 보여줍니다.

- 분리된 MoT 구조를 통해 이해 레이어를 보호하면서 하위 공유 레이어의 표현력을 강화
- 학습 완료 후 생성 브랜치를 제거하여 추론 시 추가 비용(Zero Inference Overhead) 제거

### 🧑‍💻 개발자 관점
모델의 추론 속도를 저하시키지 않으면서도 생성 모델의 풍부한 정보를 활용해 시각 이해 성능을 끌어올릴 수 있는 실용적인 학습 전략을 제시합니다.

### 🚀 실무 적용 아이디어
- 기존 MLLM의 하위 레이어에 생성 손실을 결합하는 분리형 학습 구조 구현
- 공간 이해(Spatial Comprehension) 성능 향상을 위한 생성 태스크 설계 실험
- 학습 단계별 생성 브랜치 제거 시 성능 유지 여부 검증

### ⚠️ 리스크/한계
- 학습 시에는 생성 브랜치 유지로 인해 높은 컴퓨팅 자원 필요
- 생성 태스크와 이해 태스크 간의 상관관계 설계에 따라 성능 편차 발생 가능

### 📝 초록 기반 상세 설명
최근 MLLM의 발전에도 불구하고 시각적 이해와 생성은 서로 다른 목표로 취급되어 상호 보완적 활용이 어려웠습니다. 기존 방식은 이산적 토큰화나 확산 모델 목표를 사용하여 기존 사전 학습 모델로의 직접적인 전이가 까다로웠습니다. 본 논문은 생성 작업을 표현 학습을 위한 보조 감독 신호로 재해석하는 GAS 프레임워크를 제안합니다. GAS는 분리된 MoT(Mixture-of-Transformers) 구조를 통해 하위 트렁크를 공유하면서도 생성 손실이 이해 레이어에 직접적인 간섭을 주지 않도록 설계되었습니다. 실험 결과, 학습 후 생성 브랜치를 제거함으로써 추론 오버헤드 없이 인지 및 공간 이해 성능이 크게 향상되었습니다.
