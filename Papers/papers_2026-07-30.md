### 🔑 핵심 포인트

- 실로봇 데이터 없이 고정밀 데이터만으로 즉시 배포 가능한(zero-robot post-training) 정책 학습 성공

### 🧑‍💻 개발자 관점
고가의 로봇 하드웨어 없이도 정밀한 조작 데이터를 대량으로 수집할 수 있는 방법론을 제시하여 데이터 확보 비용을 획기적으로 낮춤

### 🚀 실무 적용 아이디어
- 제공된 HiFi-UMI-2K 데이터셋을 활용하여 기존 VLA 모델의 Zero-shot 성능 테스트
- 제안된 하드웨어 구성(SLAM, 동기화 방식)을 기존 데이터 수집 파이프라인에 적용 가능한지 검토
- 데이터 정밀도 향상이 모델의 일반화 성능에 미치는 영향 분석

### ⚠️ 리스크/한계
- 특수 제작된 하드웨어 시스템에 대한 의존도가 높음
- 데이터 수집 환경과 실제 로봇 환경 간의 도메인 차이(Sim-to-Real과 유사한 문제) 존재 가능성

### 📝 초록 기반 상세 설명
로봇 조작 정책 학습은 고정밀 데이터와 확장성 사이의 트레이드오프 문제로 인해 어려움을 겪고 있습니다. 기존의 로봇 없는(robot-free) 데이터는 확장성은 좋지만 정밀도가 낮아 실로봇 학습 시 별도의 앵커 데이터가 필요했습니다. 본 논문은 데이터의 양보다 질(fidelity)을 높여 실로봇 데이터 없이도 배포 가능한 HiFi-UMI 시스템을 제안합니다. 이 시스템은 SLAM, 정밀한 상대 포즈 계산, 마이크로초 단위 동기화 및 광각 카메라를 결합하여 외부 인프라 없이 3mm 수준의 정밀도를 달성합니다. 실험 결과, HiFi-UMI 데이터로만 학습된 정책이 실로봇에서 즉시 성공적으로 작동하며 기존 텔레오퍼레이션 성능에 근접하는 성과를 보였습니다. 최종적으로 2,000시간 분량의 고정밀 데이터셋인 HiFi-UMI-2K를 공개하여 커뮤니티에 기여합니다.

![Thumbnail](images/A_New_Role_for_Relevance_Guiding_Corpus_Interaction_in_Agentic_Search_img.jpg)

### 📌 한 줄 요약
검색 에이전트의 효율성을 높이기 위해 문서 관련도를 탐색 우선순위로 활용하는 RARG 프레임워크 제안

### 🔑 핵심 포인트
- 관련도를 단순 필터링이 아닌 탐색 실행의 우선순위(Execution Prior)로 활용
- Coarse-to-fine 방식의 단계적 가이드를 통한 문서 순차 탐색 및 진입점 최적화
- 검색 매칭 결과 내에서 정보 가치가 높은 발췌문을 우선 노출하는 재순위화 메커니즘

### 🧑‍💻 개발자 관점
단순히 문서를 가져오는 RAG를 넘어, 에이전트가 방대한 데이터 속에서 정답을 찾아가는 '탐색 과정'을 최적화하는 전략을 제공합니다.

### 🚀 실무 적용 아이디어
- 기존 RAG 파이프라인에 문서 간 순차적 탐색 로직 적용 실험
- 검색 결과(grep-style)의 재순위화가 LLM의 컨텍스트 윈도우 효율에 미치는 영향 측정
- 질문 유형(단순 정보 추출 vs 복잡 추론)에 따른 RARG의 효율성 벤치마크 수행

### ⚠️ 리스크/한계
- 관련도 산출 로직에 따라 탐색 편향(Bias)이 발생할 위험
- 복잡한 탐색 단계로 인해 단순 검색 대비 오버헤드가 발생할 가능성

### 📝 초록 기반 상세 설명
기존의 검색 에이전트는 문서의 관련도를 단순히 상위 k개 선택에만 사용하며, 복잡한 질문에 필요한 세부 증거를 찾는 데는 한계가 있습니다. 직접적인 코퍼스 상호작용(DCI) 방식은 정밀한 탐색이 가능하지만, 관련도 정보가 부족하면 유용한 단서를 찾는 데 시간이 오래 걸리는 문제가 있습니다. 본 논문은 관련도를 실행 우선순위로 전환하는 RARG(Relevance-Aware RipGrep Search Agent)를 소개합니다. RARG는 문서 순서 지정, 초기 진입점 설정, 검색 결과 재순위화라는 단계적 가이드를 통해 탐색 효율을 극대화합니다. 실험 결과, RARG는 복잡한 브라우징 및 추론 작업에서 기존 방식보다 정확도와 효율성 측면에서 우수한 성능을 보였습니다.

- 특정 데이터 분포에서 symmetry-breaking 전략의 일반화 여부 확인 필요

### 📝 초록 기반 상세 설명
도메인 일반화(DG)는 분포 변화에 강건한 표현을 학습하는 것을 목표로 합니다. 기존의 CPCANet은 배치 단위의 공분산 분석을 통해 도메인 불변 구조를 추출하지만, 미니 배치 학습 시 샘플 부족으로 인해 공분산 추정이 불안정해지는 문제가 있습니다. 이를 해결하기 위해 제안된 PP-CPCANet은 공분산 계산 없이 Stiefel 매니폴드 상에서 전역 직교 기저를 학습하는 공분산 프리(covariance-free) 프레임워크입니다. 또한, 대칭성을 깨뜨리는 detached-median PP 분산 목적 함수를 도입하여 밀도 높고 강건한 최적화 신호를 확보했습니다. 실험 결과, 제안 모델은 4개의 DG 벤치마크에서 SOTA 성능과 안정적인 학습을 동시에 달성했습니다.

### 📌 한 줄 요약
엣지 디바이스의 연산 제약을 고려하면서도 동적인 UAV 움직임에 대응할 수 있는 적응형 칼만 필터 기반의 실시간 추적 파이프라인 제안

### 🔑 핵심 포인트
- 상태 의존적 운동 모델을 결합한 AKKF(Adaptive Kinematic Kalman Filter) 제안
- 엣지 디바이스 배포를 위한 연산 효율성과 추적 정확도 간의 균형 확보

### 🧑‍💻 개발자 관점
저사양 엣지 하드웨어에서 고성능 딥러닝 모델 대신 사용할 수 있는 효율적인 실시간 추적 알고리즘 설계 가이드를 제공합니다.

### 🚀 실무 적용 아이디어
- 제안된 AKKF 알고리즘을 기존 KF/EKF 모델과 연산량 및 추적 성능 측면에서 비교 실험
- 다양한 프레임 레이트(FPS) 환경에서 엣지 디바이스의 CPU/GPU 점유율 변화 측정
- 급격한 가속/회전이 발생하는 동적 시나리오에서 예측 코스팅의 복구 성능 검증

### ⚠️ 리스크/한계

### 📝 초록 기반 상세 설명
시각적으로 열악한 환경에서 UAV 스웜 운영을 위해 열적외선(TIR) 이미징 기술이 필수적입니다. 그러나 기존의 정밀도 중심 추적 방식은 엣지 디바이스의 실시간 연산 제약을 충분히 고려하지 못하며, 급격한 기동 시 기존 칼만 필터의 등속도 가정이 무너지는 문제가 있습니다. 이를 해결하기 위해 본 논문은 선형 칼만 필터의 효율성을 유지하면서 상태 의존적 운동 모델을 결합한 AKKF(Adaptive Kinematic Kalman Filter)를 제안합니다. 여기에 일시적 오탐지 억제 및 운동학 기반 예측 코스팅 기술을 결합하여 궤적 연속성을 확보했습니다. BSB 벤치마크 실험을 통해 실시간성과 추적 성능 사이의 균형을 입증하며 엣지 배포를 위한 기반을 마련했습니다.
