## 2. [Annotations as Rollouts: Efficient and Scalable Reinforcement Learning for Video MLLMs](https://huggingface.co/papers/2608.20492)
**Upvotes**: 88 | **도입 난이도**: 중 | **신뢰도**: 상
**arXiv**: https://arxiv.org/abs/2608.20492

**태그**: Video-LLM, Reinforcement-Learning, Efficiency, Multimodal, RAG, Video, Benchmark

![Thumbnail](images/Annotations_as_Rollouts_Efficient_and_Scalable_Reinforcement_Learning_for_Video_MLLMs_img.jpg)

### 📌 한 줄 요약
고비용 CoT 생성 없이도 어노테이션을 직접 최적화 타겟으로 활용하여 비디오 MLLM의 학습 효율과 성능을 극대화하는 RL 프레임워크

### 🔑 핵심 포인트
- 어노테이션을 직접적인 긍정 최적화 타겟(oracle rollout)으로 활용하는 새로운 RL 패러다임 제안
- 고득점 oracle이 학습을 방해하는 'advantage inversion' 문제를 해결하는 decoupled advantage estimator 도입
- CoT 생성 없이도 높은 성능을 내며, GRPO 대비 약 2배 이상의 학습 속도 효율성 확보

### 🧑‍💻 개발자 관점
비디오 데이터 학습 시 막대한 비용이 드는 CoT 생성 없이도, 기존의 정답(annotation)을 효율적으로 RL에 녹여낼 수 있는 실무적인 방법론을 제시합니다.

### 🚀 실무 적용 아이디어
- 기존 RL(GRPO 등) 학습 시 발생하는 advantage inversion 현상이 발생하는지 모니터링
- 보유한 정답 데이터(Ground Truth)를 RL의 oracle로 활용하는 실험 설계
- 모델 크기 및 데이터 규모에 따른 OraRL의 스케일링 효율성 검증

### ⚠️ 리스크/한계
- Oracle 데이터의 품질이 낮을 경우 전체 정책 학습이 왜곡될 위험이 있음
- 비디오 데이터 특유의 복잡한 시공간적 관계를 oracle이 충분히 반영하지 못할 가능성

### 📝 초록 기반 상세 설명
비디오 MLLM의 사후 학습(post-training) 시 기존 RL 방식은 고품질 롤아웃 확보와 CoT 생성 비용 문제로 인해 효율성이 낮습니다. 본 논문은 어노테이션이 단순 점수 부여를 넘어 직접적인 최적화 타겟(oracle rollout)이 될 수 있음에 주목합니다. 하지만 높은 보상을 가진 oracle이 베이스라인을 높여 학습을 방해하는 'advantage inversion' 문제가 발생합니다. 이를 해결하기 위해 OraRL은 정책 롤아웃과 oracle 간의 차이를 분리하여 계산하는 decoupled advantage estimator를 제안합니다. 또한 sign-balanced pruning을 통해 효율적인 샘플링을 수행합니다. 결과적으로 OraRL은 기존 GRPO 대비 훨씬 빠른 속도로 더 높은 비디오 이해 성능을 달mat했습니다.

GPU 학습 루프 내에서 CPU로 데이터를 옮기는 병목 현상 없이 고차원 영상 처리 및 거리 변환 연산을 즉시 수행할 수 있습니다.

### 🚀 실무 적용 아이디어
- 기존 scipy.ndimage 기반 전처리 파이프라인을 TorchMorph로 교체하여 속도 비교

- PyTorch 학습 루프 내에 직접 삽입하여 데이터 로딩/전처리 병목 해소 확인

### ⚠️ 리스크/한계

- GPU 메모리 사용량 증가 가능성

### 📝 초록 기반 상세 설명
기존의 scipy.ndimage는 CPU 기반의 단일 배열 연산 방식으로 인해 GPU 학습 루프 내에서 사용 시 심각한 성능 저하를 유발합니다. 또한 기존 GPU 비전 라이브러리들은 차원과 구조 요소(structuring element)의 제약이 컸습니다. 본 논문은 22개의 공용 연산자를 제공하는 PyTorch 확장 라이브러리인 TorchMorph를 제안합니다. TorchMorph는 fused CUDA 커널을 통해 최대 8차원 텐서와 배치 연산을 지원하며, scipy.ndimage와 동일한 API를 제공하여 기존 코드의 이식성을 극대화했습니다. 실험 결과, CPU 대비 최대 1,100배의 처리량을 달성하며 기존 라이브러리들과 수치적 일치성을 확보했습니다.

## 23. [Latent Action as Intention Enables Efficient Future Imagination for World Action Models](https://huggingface.co/papers/2608.24882)
**Upvotes**: 0 | **도입 난이도**: 중 | **신뢰도**: 상
**arXiv**: https://arxiv.org/abs/2608.24882

**태그**: Robotics, World Models, Latent Action, Efficient Inference, RAG, Video, Inference

![Thumbnail](images/Latent_Action_as_Intention_Enables_Efficient_Future_Imagination_for_World_Action_Models_img.jpg)

### 📌 한 줄 요약
미래 관측값 생성 없이 잠재 액션(Latent Action)을 활용하여 추론 속도와 일반화 성능을 동시에 잡은 로봇 제어 모델

### 🔑 핵심 포인트
- 미래 관측 영상 생성 과정을 생략하고 압축된 잠재 액션(Latent Action)을 활용하여 추론 효율성 확보
- 이산 토크나이저와 액션 프리 사전 학습을 결합하여 조작에 특화된 코드북 타겟 생성
- 미래 영상 생성 없이도 미래 의도를 반영할 수 있어 높은 일반화 성능과 낮은 지연 시간 달성

### 🧑‍💻 개발자 관점
실시간 로봇 제어에서 필수적인 '낮은 지연 시간'과 '높은 일반화 성능' 사이의 트레이드오프를 효과적으로 해결하는 구조를 제시합니다.

### 🚀 실무 적용 아이디어
- 제시된 이산 토크나이저 기반의 코드북 생성 방식이 특정 도메인(예: 정밀 조립)에서 어떻게 작동하는지 검증
- 데이터 부족 상황(Few-shot)에서 기존 Fast-WAM 방식과 LAWA의 성능 격차 비교 실험
- 실제 로봇 하드웨어 환경에서의 추론 지연 시간(Latency) 및 제어 주기 안정성 테스트

### ⚠️ 리스크/한계
- 잠재 공간(Latent Space)에 의존하므로, 시각적 피드백이 복잡한 환경에서 디테일한 제어가 어려울 가능성 존재
- 코드북 설계 및 이산 토크나이저 학습에 따른 하이퍼파라미터 민감도

### 📝 초록 기반 상세 설명
로봇 제어를 위한 World Action Models(WAMs)는 미래 관측 변화를 모델링하지만, 테스트 시 미래 영상을 생성하는 과정에서 발생하는 지연 시간이 큰 문제였습니다. 이를 해결하기 위해 미래 영상 생성을 생략하는 Fast-WAM 방식이 제안되었으나, 데이터가 부족하거나 분포 외(OOD) 상황에서 일반화 성능이 떨어지는 한계가 있었습니다. 본 논문은 잠재 액션을 미래 의도의 운영 표현으로 사용하는 LAWA 아키텍처를 제안합니다. LAWA는 액션 프리 사전 학습을 거친 이산 토크나이저를 통해 조작 중심의 코드북 타겟을 생성하며, 미래 비디오 생성 없이도 잠재 상태와 실행 가능한 액션 청크를 공동으로 디노이징합니다. 실험 결과, LAWA는 RoboCasa 벤치마크에서 기존 Fast-WAM 대비 높은 성공률을 기록했으며, Joint-WAM 수준의 성능을 유지하면서도 추론 지연 시간을 42.9% 단축했습니다.
