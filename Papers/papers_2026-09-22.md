## 1. [Grounded Skill Synthesis from Code at Scale for Agentic Intelligence](https://huggingface.co/papers/2609.05571)

**arXiv**: https://arxiv.org/abs/2609.05571

**태그**: Agent, Code-to-Skill, Automated-Pipeline, Software-Engineering, RAG, Benchmark, Evaluation

![Thumbnail](images/Grounded_Skill_Synthesis_from_Code_at_Scale_for_Agentic_Intelligence_img.jpg)

### 📌 한 줄 요약
소스 코드를 활용해 실행 가능한 에이전트용 스킬 뱅크를 자동 구축하고 성능을 검증하는 파이프라인 제안

### 🔑 핵심 포인트
- 소스 코드를 기반으로 실행 가능한(grounded) 에이전트 스킬을 추출하는 자동화 파이프라인 개발
- 100만 개 이상의 검증된 스킬을 포함하는 대규모 데이터셋 CodeSkillBank 구축
- 트래젝터리 기반 방식보다 우수하며, AI 생성 코드에서도 높은 신뢰도를 보이는 스킬 합성 능력 입증

### 🧑‍💻 개발자 관점
에이전트가 학습 데이터나 환경 상호작용 없이도 기존 소프트웨어 생태계의 코드를 통해 즉각적인 실행 능력을 확보할 수 있는 경로를 제시합니다.

### 🚀 실무 적용 아이디어
- 오픈소스 라이브러리 코드를 활용해 특정 도메인 특화 스킬셋 구축 실험
- LLM의 RAG 시스템에 CodeSkillBank와 같은 구조화된 코드 스킬을 주입하는 프로토타입 개발
- AI가 생성한 코드와 인간이 작성한 코드 간의 스킬 추출 품질 비교 테스트

### ⚠️ 리스크/한계
- 추출된 스킬이 실제 복잡한 동적 환경에서 의도대로 동작할지에 대한 실시간 검증 필요성
- 코드 구조의 변화나 의존성 문제로 인한 스킬의 유효성 유지 문제

### 📝 초록 기반 상세 설명
에이전트의 확장성을 위해 재사용 가능한 스킬 확보가 필수적이지만, 기존의 트래젝터리 기반 방식은 환경 의존적이고 문서 기반 방식은 실행 검증이 어렵다는 한계가 있습니다. 본 논문은 소스 코드를 활용해 실행 가능한 근거를 확보하면서도 사전 경험 없이 스킬을 추출하는 Code2Skill 파이프라인을 제안합니다. 이 파이프라인은 코드 단위를 원자적 작업, 복합 워크플로, 반복 패턴으로 변환한 뒤, 소스 코드 없이 재구성하거나 비교하는 방식을 통해 검증합니다. 19,769개의 GitHub 저장소를 활용해 100만 개 이상의 검증된 스킬 데이터셋인 CodeSkillBank를 구축했습니다. 실험 결과, Code2Skill로 증강된 모델은 기존 베이스라인 대비 평균 11.7% 성능 향상을 보였으며 트래젝터리 기반 방식보다 우수한 성능을 기록했습니다.

- 압축 모델의 Catastrophic Failure 여부를 확인하기 위한 스트레스 테스트 수행

### ⚠️ 리스크/한계
- Ternary와 같은 극단적 압축 방식은 특정 도메인에서 치명적인 성능 저하를 유발할 수 있음
- 제안된 프로토콜이 특정 이미지 모달리티에 최적화되어 있을 가능성

### 📝 초록 기반 상세 설명
줄기세포 배양을 위한 세그멘테이션 파운데이션 모델의 엣지 디바이스 배포 수요가 증가하고 있습니다. 하지만 기존 압축 방식은 다양한 이미지 모달리티에서의 성능 저하를 보장하기 어렵다는 문제가 있습니다. 본 연구는 특정 성능 유지 임계치를 기준으로 Cellpose-aks의 양자화를 평가하는 프로토콜을 제안합니다. 다양한 밀도와 모달리티를 포함한 176개 필드 데이터셋을 통해 압축 효율과 성능 유지 사이의 관계를 분석했습니다. 실험 결과, W8A16 방식과 민감도 기반 혼합 W4/W8 방식은 성능 저하 없이 높은 압축률을 달성했으나, Ternary 방식은 심각한 성능 실패를 보였습니다. 결과적으로 단일 지표가 아닌 모달리티별 성능 유지를 중심으로 한 압축 평가의 중요성을 입증했습니다.
