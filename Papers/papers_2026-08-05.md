![Thumbnail](images/VAD_Attributing_Visual_Evidence_for_Target_Reconstruction_in_Multimodal_On-Policy_Distillation_img.jpg)

### 📌 한 줄 요약
시각적 증거와 언어적 편향을 분리하여, 교사 모델의 피드백 중 순수하게 시각 정보에 기반한 부분만 정교하게 추출하는 증류 기법

### 🔑 핵심 포인트
- 시각적 증거와 언어적 편향이 혼재된 교사 피드백에서 순수 시각적 기여도(Visual Attribution)를 분리하는 메커니즘 제안
- 카운터팩추얼(Counterfactual) 접근법을 통해 증거 유무에 따른 확률 변화를 기반으로 시각적 기여 방향(ut) 산출
- 추출된 시각적 성분을 활용한 타겟 재구성을 통해 학생 모델에 최적화된 정교한 학습 신호 제공

### 🧑‍💻 개발자 관점
멀티모달 모델 학습 시 교사 모델의 언어적 편향(Hallucination 등)이 학생에게 전이되는 문제를 방지하고, 순수 시각 정보 기반의 정교한 지식 전이가 가능합니다.

### 🚀 실무 적용 아이디어
- 기존 멀티모달 증류 파이프라인에 VAD의 카운터팩추얼 확률 차이 로직 적용 테스트
- 시각적 정보가 핵심인 VQA(Visual Question Answering) 데이터셋에서의 성능 향상 폭 검증
- 언어적 편향이 강한 데이터셋에서 VAD의 필터링 효과 분석

### ⚠️ 리스크/한계
- 카운터팩추얼 계산을 위한 추가적인 추론/연산 비용 발생 가능성
- 시각적 증거가 매우 미미한 태스크에서는 기여도 추정의 불안정성 우려

### 📝 초록 기반 상세 설명
멀티모달 온폴리시 증류(OPD)는 교사 모델의 지식을 학생 모델로 전달하지만, 교사의 피드백이 시각적 신호와 언어적 사전 지식이 뒤섞여 있어 순수 시각적 기여도를 파악하기 어렵습니다. 이를 해결하기 위해 본 논문은 시각적 증거에 의한 기여도를 추정하는 VAD(Visual Attribution Distillation) 알고리즘을 제안합니다. VAD는 특정 증거가 있을 때와 없을 때의 확률 변화를 이용한 카운터팩추얼(Counterfactual) 방식을 통해 시각적 기여 방향을 정의합니다. 추출된 시각적 성분을 바탕으로 학생 모델에 최적화된 타겟을 재구성하여 학습 신호로 사용합니다. 실험 결과, VAD는 기존의 직접적인 증류 방식보다 우수한 성능을 보였으며 시각적 증거가 중요한 태스크에서 더욱 효과적임을 입증했습니다.

## 36. [SG-WAM: Self-Guided World Modeling in Geometry-Aware Policy Space](https://huggingface.co/papers/2608.01397)
**Upvotes**: 1 | **도입 난이도**: 상 | **신뢰도**: 상
**arXiv**: https://arxiv.org/abs/2608.01397

**태그**: Robot-Control, World-Models, Reinforcement-Learning, Computer-Vision, RAG, Vision, Evaluation, Safety

![Thumbnail](images/SG-WAM_Self-Guided_World_Modeling_in_Geometry-Aware_Policy_Space_img.jpg)

### 📌 한 줄 요약
정책 공간 내 기하학적 구조를 반영한 자기 주도형 월드 모델링을 통해 로봇 제어 성능을 극대화한 프레임워크

### 🔑 핵심 포인트
- 정책 유도 표현 공간(Policy-derived representation space) 내에서 직접적인 동역학 학습
- EMA 기반의 자기 주도형 타겟 생성을 통한 안정적인 미래 상태 예측
- 기하학적 감독(Geometric supervision)을 통한 공간 정보와 액션 간의 정렬 확보

### 🧑‍💻 개발자 관점
로봇 제어 시 관찰 데이터의 복잡도를 줄이면서도, 액션과 밀접하게 연관된 핵심 기하학적 정보만을 효율적으로 모델링하는 방법을 제시합니다.

### 🚀 실무 적용 아이디어
- 제시된 EMA 기반 타겟 생성 방식이 학습 안정성에 미치는 영향 분석
- Flow-matching 기반 액션 생성과 잠재 공간 동역학 간의 결합도 테스트
- 다양한 로봇 환경에서의 기하학적 감독(Geometric supervision) 가중치 실험

### ⚠️ 리스크/한계
- 정책 백본에 의존적인 타겟 생성 방식이 특정 도메인에서 편향을 유발할 가능성
- 복잡한 기하학적 구조를 가진 환경에서의 일반화 성능 검증 필요

### 📝 초록 기반 상세 설명
기존의 World Action Models(WAMs)는 미래 상태 예측 시 관찰 공간의 연산 부하가 크거나, 액션 생성과 기하학적 구조가 정렬되지 않는 문제가 있었습니다. 이를 해결하기 위해 SG-WAM은 정책 유도 표현 공간 내에서 기하학적 인지 능력을 갖춘 동역학을 학습하는 프레임워크를 제안합니다. 학습 과정에서 EMA(Exponential Moving Average)를 통해 정책 백본의 복사본을 타겟으로 사용하여 안정적인 감독을 제공하며, 기하학적 감독을 통해 공간적 맥락을 확보합니다. 제안된 방식은 잠재 미래 예측, 기하학적 접지, Flow-matching 기반 액션 생성을 엔드투엔드로 통합하여 최적화합니다. 실험 결과, 대규모 사전 학습 없이도 LIBERO 벤치마크에서 높은 성공률을 기록하며 실세계 OOD(Out-of-Distribution) 환경에서도 강력한 성능을 입증했습니다.

### 📌 한 줄 요약

### 🔑 핵심 포인트
- 사전 학습된 모델의 백본을 동결하고 가벼운 어댑터 헤드만 학습하는 효율적인 전략 제안

- 실제 데이터 없이 모델 생성 샘플만으로도 고품질의 디테일 보강 학습 가능

### 🧑‍💻 개발자 관점
모델 전체를 재학습하지 않고도 1% 미만의 비용으로 생성 품질을 개선할 수 있어, 기존 모델의 성능을 업그레이드할 때 매우 실용적인 접근법입니다.

### 🚀 실무 적용 아이디어
- 기존 픽셀 기반 확산 모델에 가벼운 예측 헤드를 부착하여 성능 변화 확인
- 실제 데이터셋 대신 생성된 합성 데이터만으로 어댑터 학습 효율성 테스트
- 레이어별 주파수 분리 특성이 다른 다양한 아키텍처에서의 일반화 성능 검증
