### 📰 원문 핵심 요약
Rust의 대표 난수 라이브러리인 rand는 기능이 여러 트레이(trait)에 분산되어 있어 사용성이 복잡하다는 문제를 안고 있었습니다. 이를 해결하기 위해 개발자는 더 작은 API 표면과 일관된 사용 경험을 제공하는 urandom 라이브러리를 새롭게 개발했습니다. urandom은 고수준 연산을 하나의 Random 구조체로 통합하고 Rng 트레이를 봉인(sealed)하여, 단순한 임의 생성기 지원을 넘어 더 예측 가능한 개발 환경을 구축하는 데 중점을 둡니다.

### 📌 왜 중요한가
이번 소식은 복잡한 API 설계를 단순화하여 개발자의 실수 가능성을 줄이고 유지보수성을 높이는 것이 라이브러리 설계의 핵심임을 보여줍니다. 기능의 확장성보다 일관된 사용 경험과 최소한의 인터페이스를 제공하는 것이 현대적인 라이브러리 설계의 중요한 방향성임을 시사합니다.

### ✅ 지금 확인할 포인트
- 기존 rand 크레이트의 분산된 연산 구조를 개선하기 위해 urandom을 새롭게 개발했습니다.
- 고수준 연산을 단일 Random 구조체로 모아 API 노출 면적을 최소화했습니다.
- Rng 트레이를 봉인하여 일관된 사용 경험을 유지하고 구현의 복잡도를 낮췄습니다.
