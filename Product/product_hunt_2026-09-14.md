### 📌 이 서비스 한눈에 보기
로컬 우선 방식의 오픈소스 다국어 번역 스프레드시트 및 MCP 서버

### 🔑 주요 기능
- JSON, Excel, CSV, Flutter ARB, iOS/Android 형식 간 자유로운 변환
- 변수 손실 없는 AI 번역 및 Zawgyi 유니코드 변환 지원
- GitHub PR 자동 동기화 및 로컬 우선(Local-first) 워크스페이스

### 🙋 사용자에게 어떤 점이 좋은가
개발자가 번역 파일을 수동으로 변환하는 번거로움을 줄이고, 코드와 번역 데이터 간의 동기화를 자동화하여 i18n 워크플로우를 간소화할 수 있습니다.

### ✅ 지금 바로 써볼 기능
- 기존 JSON/CSV 파일을 불러와 다양한 플랫폼 형식으로 변환해보기
- AI 번역 기능을 활용해 변수 구조를 유지하며 번역 테스트하기
- GitHub 연동을 통한 자동화 워크플로우 설정하기

### ⚠️ 사용 전 확인할 점
- 로컬 우선 방식이므로 팀 협업 시 데이터 동기화 방식 확인 필요
- AI 번역 결과물의 문맥 적합성 검토 필요

### 🧭 확인이 더 필요한 정보
로컬 데이터 저장 방식과 클라우드 협업 기능 간의 구체적인 동기화 메커니즘 확인이 필요합니다.
